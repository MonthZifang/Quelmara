## 安全证明与边界

仅当无条件跳转目标能沿 NOP/LAB 顺序到达、期间没有任何实际指令时，将 JMP 原地替换 NOP。
不插删IR索引，不改变标签ID、条件跳转、操作数/活跃区间或副作用；未知/访存/调用/存储均是屏障。
回边、缺失目标、越过实际指令的目标均不变。晚期调用处理DCE新暴露的透明间隙。
