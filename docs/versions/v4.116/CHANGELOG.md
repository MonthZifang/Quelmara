## 优化形状

`vec.get/set` 降级出 `LOADD data,[h+0]` + `LOADX elem,[data+i*8]`。循环内
无 push/调用时 `[h+0]` 逐轮不变却每轮重装（b28 内层每轮 2 条、b70 每轮 1 条）。
块内融合（`_opt_fuse`）只消同一表达式内的重复装载，跨迭代的外提需要循环判据。
外提后循环内只剩元素访存，与 C 的基址读一次对齐。

## 安全判据（每条可证明，宁缺毋滥）

1. 结果 dst 单定义临时值（ndef==1、vpin==0、非聚合非 f64）。
2. 基址 pinned、单定义、定义点无条件可达（形参帧入口必达；或不在任何循环、
   不被任何跳转跳过）——保证预头装载不变成投机访存。
3. 循环体无调用族，**与 `_alloc` 的 cp[] 屏障清单完全一致**：CALL*/ARG/STKARG
   以及内部发调用的 COPY/MEMCPYN/ZERON/RETAGG。
4. 循环体内存写不落在基址的 MOV/ADDRF 别名闭包上（元素 store 放行，头块写拒绝）。
5. 体内指令全在白名单（纯寄存器运算/读/控制流），未知操作码拒绝。
6. **寄存器压力闸**：循环体自身定义的不同临时值数 D≤3 才提（临时池仅 R8-R11
   四个，外提值整段占一个）；每个循环头至多提一条。
7. **同一循环头合并所有回边**（continue 会发第二条 JMP），e 取最大值。

## 开发中踩掉并修复的四个坑（全部有实测现象）

| 坑 | 现象 | 修复 |
|---|---|---|
| 外提值活跃区间不跨回边 | 夹具 case6 段错误：分配器在循环内复用外提值寄存器，下一轮读垃圾 | vend 钉到回边（与 S_FOR"上界必须钉进变量"同坑） |
| 批量外提后下标过期 | stage-2 编 vec 循环栈溢出：内层循环 (h,e) 失效、改错指令 | 每次重扫只提一条，_ir_insert 统一维护区间偏移 |
| 调用族清单漏 COPY/MEMCPYN/ZERON/RETAGG | stage-2 栈溢出：vec[Ir] 聚合 COPY 内部 __memcpy 清掉外提指针所在 caller-saved 寄存器 | 与 _alloc cp[] 清单对齐 |
| continue 多回边截断循环体 | stage-2 栈溢出：逐回边当独立循环，截断范围外的调用漏检 | 按头合并回边，e 取最大 |

另有**寄存器压力回退**：无闸版本 b28/b22/b18 慢 2.4×（外提值挤占临时池 →
溢出，b28 帧 312→328B），加 D≤3 闸后回退全部消失。

## 已知边界 / 遗留

- 收益集中在**单基址、低临时压力**的读循环：最大 b61_cache_scan −43%、
  b52_io_scan −22%（外提打断"头指针→元素"的依赖装载链），b23/b69/b70/b27/b79
  −4~−6%。多基址或高压力循环被压力闸保守拒绝——这是有意的：临时池只有 4 个，
  外提的净收益取决于省下的装载 vs 挤出的溢出，逐基准实测为净亏的不提。
- 根本提升数组密集基准仍需 vec 内联布局（前置 &T 引用语义，见
  `docs/handoff/VEC-INLINE-PLAN.md`），本版是其外的安全增量。
- 外提只动 LOADD（头指针/字段指针），LOADX 元素装载不外提（依赖下标，非常量）。
