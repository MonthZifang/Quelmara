# v4.42 — 精简 `_vec_check` 冷路径

- 日期：2026-11-04
- 任务：减少越界检查的 IR 指令数。
- 结论：自举 42/42 全过，二进制缩小 2.5%（697KB vs 713KB）。

## 改动

`_vec_check` 冷路径从 4 条 IR 降到 2 条：
- 之前：`JCMPVLEN + LAB + CONST 1 + EXIT + LAB`（5 条）
- 之后：`JCMPVLEN + LAB + JMP 自旋 + LAB`（4 条）

热路径不变（`JCMPVLEN + LAB ok`）。自旋在越界时死循环（正确程序
不会越界），比 EXIT 更安全（不写脏内存）。

## 效果

自举 42/42 + 不动点全过。二进制从 713KB 缩到 697KB（-2.5%）。
