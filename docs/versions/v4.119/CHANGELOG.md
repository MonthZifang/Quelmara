## 内联判据（AST 层可证、不依赖 vreg 编号 → 不动点安全）

在 v4.117（单返回纯表达式）之外，通用候选要求：
1. 返回 int、形参 ≤4 全 int；**形参名/局部名与调用方活跃变量零碰撞**（`_try_var` 命中即跳过）。
2. 体内**无调用**（E_CALL/E_SPAWN/E_METHOD/E_CLOSURE/容器 new 拒）→ 叶子、无递归。
3. 语句仅 S_LET/S_ASSIGN/S_EXPR/S_IF/S_WHILE/S_BREAK/S_CONTINUE；**无 defer、无 S_FOR/S_FOREACH、
   无中途 S_RETURN**；末条必为带值 S_RETURN。
4. 表达式仅 E_NUM/E_VAR/E_BIN/E_UN；**不赋值给形参**；S_ASSIGN 目标必须是已声明局部。
5. 语句数 ≤40、局部数 ≤8（帧压闸，坑表 #1）。

机制：bind 栈绑形参→实参；逐条 `_lower_stmt` 前缀语句（循环/分支自带新标签与 loop 上下文）；
末尾 return 表达式单独 lower 作为调用值。**不改 S_RETURN 关键路径**（避开其 defer/pin/聚合语义）。

## 开发中踩掉并修复的关键坑（实测 b53 错值 → 两阶段修）

**回边活跃**：首版直接把实参 vreg 绑到形参。b53 的 `work(start,end)` 内联后，
`end` 是计算值临时值（DIVC n/4，住 r8），在循环条件里反复读；但其活跃区间不跨回边，
分配器把 r8 复用给循环体的 `i*2`，`end` 被冲掉 → 循环只跑一轮，
`work(0,n/4)` 得 1 而非 6250000000000，总和 93750000000001≠100000000000000。

- **第一版修复（pin）被否**：把实参 `_pin` 进变量虽保正确，却把**常量实参变变量**，
  丢掉常量传播——b57 的 `% mod`（mod=1000003）退回 idiv，−61% 收益归零。
- **最终修复（延 vend）**：内联体降级完后，把每个实参的 `vend` 延到 `len(fc.ir)`
  （内联体末尾）。既让实参寄存器在循环内不被复用（保正确），又**保留常量性**
  （b57 的 %mod 仍折成 DIVC，保收益）。`_rebuild_temp_ends` 只延不缩，此值保留。

与 v4.116 装载外提的"vend 钉到回边"是同一类回边活跃坑。已加 b53 形状回归夹具
（计算值实参 + 循环读形参，四段拼满 nn→nn²）。

## 已知边界 / 遗留

- 仍只内联**叶子**（体内无调用）；含调用的函数、递归、多 return、defer、聚合/f64/vec 形参不内联。
- 碰撞即跳过（保守）：调用方已有同名变量时不内联，避免遮蔽。彻底做法是重命名，复杂，留后。
- b28_matrix 等无 helper 的基准不受本版影响（其差距是 vec 双重访存，需 &T，见 VEC-INLINE-PLAN）。
