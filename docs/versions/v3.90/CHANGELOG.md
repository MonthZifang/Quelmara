# v3.90 — 条件减改无分支（`cmovns`）：`b1_int` 1.49× → **0.96×**

- 日期：2026-11-02
- 任务：收 §7.31 (a) —— `b1_int` 一直慢 1.48×，v2.88 试过无分支版失败。
- 结论：**成功**。`b1_int` 从慢 1.49× 变成**快 0.96×**。
- 影响面：`bootstrap/qlmc/qlmc.qma`（新操作码 `OP_CSUBNS` + `_cmovns` 编码器
  + 发射器 + `_mod_ind_apply` 换用它）、`tests/selfhost/s48_csub.qma`（新夹具）、
  `tests/qlmc_test.py`（登记 s48）、`docs/07-gaps.md`、`docs/06-status.md`

## 关键差别：为什么这次成了，v2.88 没成

v2.88 试过纯算术的无分支回绕：

```
t = v - D
m = t >> 63      ; t < 0 时 m = -1
m = m & D        ; t < 0 时 m = D
v = t + m
```

**它要两个 IR 级临时值**（`t` 和 `m`）。`b1_int` 的 `main` 里同时活着
`n`/`acc`/`i`/`v`，变量寄存器池只有 7 个 —— 挤不下，`t`/`m` 溢出到帧槽，
热循环里凭空多两次访存。实测 **21 ms → 138 ms（慢 6.6×）**，回退。

这次的 `cmovns` 版只需要**一个**暂存，而且那个是**发射器专用的 RAX**
（不参与寄存器分配、永远不会被分配给任何 vreg）：

```asm
mov    rax, rsi      ; rax = 原值
sub    rax, 0xd      ; rax = 原值 - D
mov    rsi, ...      ; （dst 与 src 不同才需要）
cmovns rsi, rax      ; **减完非负**才采纳
```

**IR 层一个临时值都不多要** —— 这是两者的本质区别。v2.88 的结论
"无分支版在这里不划算"是对的，但它归因于"无分支"本身，
实际归因应该是"**要了几个 IR 级临时值**"。

## 踩到的坑：`cmovns` 的方向

第一版写成了：

```asm
mov  rax, 原值
sub  rsi, imm      ; rsi = 原值 - D
cmovns rsi, rax    ; ← 错：原值非负就退回原值
```

`cmovns` 的语义是"**src 最高位为 0 时 dst = src**"，所以 src 必须是
**减完**的值、dst 是**原值**。写反之后 `b1_int` 从 `119999988` 变成
`-1199999940000000`。

正确写法：

```asm
mov  rax, 原值
sub  rax, imm      ; rax = 减完
mov  rsi, 原值     ; dst = 原值
cmovns rsi, rax    ; 减完非负才采纳
```

## 实测（公平对比：两边都是 PE + wine，取最小）

| 基准 | stage-0 | v3.89 | **v3.90** | 比值 |
|---|---|---|---|---|
| `b1_int` | 65.9 ms | 98.0 ms | **63.1 ms** | **0.96×（快）** |
| `b9_json` | 77.1 ms | 98.2 ms | 98.5 ms | 1.28× |
| `b2_float` | 102.0 ms | 81.3 ms | 81.1 ms | 0.80× |
| `b7_sort` | 99.0 ms | 56.6 ms | 57.3 ms | 0.58× |

`b1_int` **从 1.49× 慢变成 0.96× 快**，收掉约 35 ms。其余三项在噪声内。

反汇编确认循环体从 9 条降到 **6 条**，与 stage-0 同构：

```asm
add  %rsi,%r12        ; acc += i
add  $0x1,%r13        ; i++
add  $0x7,%rsi        ; v += 7
mov  %rsi,%rax        ; rax = v
sub  $0xd,%rax        ; rax = v - 13
cmovns %rax,%rsi      ; v = (v-13 >= 0) ? v-13 : v
jmp  loop
```

## 新夹具 `s48_csub.qma`

钉的是**回绕的边界**：`v` 恰好等于 `D`、`D-1`、`D+1`、`2D-1` 时都必须
只减一次（不能减两次、也不能不减）。覆盖 5 个常见除数、3 个"每轮都回绕"
的形状、2 个大步长（一次加可能跨过 D）。14 行输出与 stage-0 逐字节一致。

**为什么必须有它**：减错一次是**静默错值**，不崩不报错。v2.88 那次
`0x4D`/`0x49` 的 REX 笔误就是这么漏过去的 —— 只有逐字节差分能抓。

## 教训

**"这个优化不划算"的结论要归因到具体机制，不能停在"这个形状不行"。**
v2.88 说"无分支版慢 6.6×"，但真正的原因是"多要两个 IR 临时值挤爆了寄存器池"。
换个只要一个发射器暂存的写法，同一个优化立刻从 −6.6× 变成 +35 ms。
