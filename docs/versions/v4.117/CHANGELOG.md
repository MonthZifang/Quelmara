## 根因与方案

v4.115 公平化 + v4.116 装载外提后，剩余最大比值项 **b36_call**：
`add3(a,b,c){return a+b+c}` 是 9 条 IR 的叶子函数，C 直接内联成 `acc+=i+1`，
qlmc 每次发完整 CALL（3×ARG + shadow space + 序言/尾声），10.5× 慢。
根因是**没有函数内联**（架构勘察见 `docs/handoff/PERF-ROADMAP.md`）。

本版做**第一批最保守内联**：只内联"单返回纯表达式叶子函数"。

## 内联判据（全部 AST 层可证，不依赖 vreg 编号 → 不动点安全）

1. 有函数体（非 @ffi）、返回 `TY_INT`、形参 ≤4 且全为 `TY_INT`（排除窄整数/聚合/f64/vec）。
2. 函数体恰为**一条 S_RETURN**（`nx==-1`），返回一个表达式。
3. 表达式是**纯树**：仅 `E_NUM / E_VAR / E_BIN / E_UN`，且每个 `E_VAR` 必须是
   本函数形参（不碰全局/调用方变量，杜绝名字解析歧义）。
4. 表达式节点数 ≤25（帧压闸，坑表 #1）。

表达式无调用 → 天然叶子、无递归、无环；内联不引入控制流拼接，无需返回拦截/标签重命名。

## 机制

调用点实参已 lower 成 vreg 后，用现成的 `_bind_push` 把形参名绑到实参 vreg
（`_try_var`/`_var_id` 先查 bind 栈），直接 `_lower_expr` 返回表达式，结果即调用值；
压/弹严格配对，lower 完即弹，不污染调用方作用域。**复用既有 bind 栈，零新增状态。**

夹具覆盖：基本内联 / 变量实参 / 多形参表达式 / 无形参常量 / 单形参恒等 /
位运算 / 一元负号 / 移位 / 除法取模 / **调用方与形参同名（bind 不污染）** /
嵌套内联实参 / 循环内反复内联 / 含调用·含循环·多语句的**不该内联函数仍正确**。

## 已知边界 / 遗留

- **只内联单返回纯表达式**：含循环的函数（如 b57_pow_mod 的 pow_mod）本版不内联，
  需返回拦截（RET→MOV+JMP）+ 标签重命名，留下一版。b57 的 4× 差距仍在。
- b36 内联后仍 ~2.2× C（C 的循环调度更紧），剩余差距是寄存器分配/指令调度，
  非调用开销；调用开销这一根因已消除。
- 内联决策是 AST 纯函数，候选函数本体仍照常编译发射（不做死函数消除），
  仅调用点被替换，代码体积略增。
