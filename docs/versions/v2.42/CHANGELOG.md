## 做法：口径逐行对齐 stage-0 的 `__f64_to_str`

`__f64_fmt(rcx = 缓冲, rdx = 源槽) -> rax = 长度`：

| 区间 | 做法 |
|---|---|
| `\|x\| == 0` | `0`（`-0.0` 也是 `0`） |
| NaN / ±inf | `nan` / `inf` / `-inf`（全按位模式判，不靠浮点比较） |
| `1e-6 <= \|x\| < 1e12` | 定点：`u=(i64)(\|x\|*1e6+0.5)`、`ip=u/1e6`、`fp=u%1e6`；打印 ip，`fp≠0` 时 `.` + 6 位零填充 + 去尾零 |
| 其余 | 科学计数：归一到 `[1,10)` 数指数，`m=(i64)(x*1e6+0.5)`（进位到 1e7 时回退一位并 +1），打印尾数 + 去尾零，再打 `e` ± 指数 |

两条分支都算出 `(ip, fp, exp)` 之后走**同一段输出代码**（`exp = -9999` 表示"定点，无指数"），
避免重复。状态全放栈槽（调 `__i64_fmt` 时所有易失寄存器都不保）。

## 这轮的关键教训（已进坑表）

**小数那 6 位必须用只碰低寄存器的除法循环**（`rcx`/`rdx`/`rax` 都是低编号，不需要 REX.R/X）。
v2.40 那次用 `r9`/`r10` 做下标，REX 前缀连错三处 —— `lea r9,[rcx+r10±k]` 要 `0x4E`（W|R|X）、
`mov byte [rcx+r10],imm` 要 `0x42`（X）—— 结果不是崩就是打出常数，白折腾一整轮。

另外这次替换代码块时**把 `.zero/.nan/.inf` 三块一起吃掉了**（只核了边界字符串没核内容），
现象是"前 5 行对、第 6 行崩"。教训：替换大段代码后要用 `grep` 确认所有 label 都还有定义。
