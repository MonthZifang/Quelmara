# v3.71 — `vec[vec[T]]` 落地：类型码改类型表下标；覆盖率 67 → 68

- 日期：2026-11-01
- 任务：用户要求"继续"。收 §7.18（追了 8 轮的架构缺口）。
- 影响面：`bootstrap/qlmc/qlmc.qma`、`tests/selfhost/s39_nestedvec.qma`、
  `tests/qlmc_test.py`、`tools/dev/qlmc_coverage.py`（`BASELINE` 67 → 68）
- 覆盖率：**67 → 68**（`std/csv` 解开）
- qlmc 差分：40 → **41**

## 核心改动

`TY_VEC` 的载荷从"**完整元素类型码**"改成"**类型表下标**"：

```quelmara
// 老写法：vec[vec[str]] = 0x8000 + 0x8002 = 0x10002  ← 进位撞 TY_MAP
// 新写法：vec[vec[str]] = 0x8000 + ti                ← ti < 2048，永远在原区间
```

类型表放在 `stt` 尾部（`VTYPES_BASE`，2048 槽），**零新增字段、零新增形参**。

**关键收益**：`ti < 2048 < 0x8000`，所以 `TY_VEC + ti` **永远落在
`[0x8000, 0x10000)` 内** —— 那 8 处 `>= TY_VEC && < TY_MAP` 的区间判断
**一行都没改**。（v3.64 的预判是对的。）

## 踩到的坑（这一轮最贵的教训）

改完之后 stage-1 全绿（40/40 差分、68/69 覆盖率、嵌套语义完全正确），
**但 stage-2 崩**（编任何程序 rc=5）。

追了整整 **8 轮**才找到根因，中间被两次假象误导：

1. **被文件名骗**：`s1_v365b.exe` 实际是"用含类型表的源码编的"，
   不是 v3.65 提交版；`s1_nested.exe` 是**缓存命中**的旧产物
   （144 ms "完成"）。拿它们当基线，结论全错。
2. **被 IR 相同骗**：两个 stage-1 的 `_ty_size` / `_opt` / `_emit_fn` /
   `_alloc` 的 IR **完全相同**，于是排除了"IR 生成有 bug"，
   转而去查机器码 —— 方向错了。

## 真正的根因

给 qlmc 加了 `addrdump`（v3.69）之后，一次编译内就定位到
`_prescan_imports` 的 555 条 IR 里**只有 2 条不同**：

| IR# | 坏的 | 好的 | 含义 |
|---|---|---|---|
| 11 | `BINI a=7 b=43(SHL) imm=3` | `imm=6` | `1<<3`=8 vs `1<<6`=64 |
| 68 | `BINI a=46 b=43(SHL) imm=3` | `BINI a=46 b=5(MUL) imm=56` | `46*8` vs `46*56` |

**IR#68 是决定性的**：`56` 不是 2 的幂，强度削减**根本不该触发**。
所以 `cv` 被算成了 **8**。

根因在这一行：

```quelmara
// _lower_vecnew 里
let stride = _ty_size(fc, nd.a)     // ← nd.a 现在是【vec 类型码】！
```

`nd.a` 改成存 `TY_VEC + ti` 之后，`_ty_size(TY_VEC+ti)` 走
`ty >= TY_VEC && ty < TY_SLICE { return 8 }` —— **永远返回 8**。
所有 `vec[Struct]` 的元素步长都塌成 8。

**修法**：先 `_vtypes_elem(fc.stt, nd.a)` 换回元素类型码，再传给 `_ty_size`。

## 这个 bug 为什么难抓

* **IR 层面完全正确**（两个编译器的 IR 一模一样）—— 所以 `irdump` 对比
  一切正常，看不出问题；
* 症状是 `vec[Struct]` 步长错，但**探针程序全部正确** —— 因为探针里
  `vec[Node].new()` 走的路径没有触发（只有 qlmc 自身规模下才暴露）；
* 表现为"stage-2 崩"，而 stage-2 崩溃本身又被 wine 环境限制混淆了 3 轮。

**教训**：`_ty_size` 的入参语义（元素码 vs vec 码）是**隐式契约**，
改动 `nd.a` 的含义时必须全文搜它的所有消费点。这一处漏了。
