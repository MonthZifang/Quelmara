# v2.69 — 标志位循环换成 break（`while go == 1 && p < n`）

- 日期：2026-10-27
- 任务：继续压 b9_json 的每字节开销
- 影响面：`tools/stage0/qlm_opt.py`（新 pass `opt_flag_loop`）
- 夹具：`tests/t150_flag_loop.qma`

## 根因：`&&` 的守卫每轮付两次比较、两个分支

`while go == 1 && p < n { ... }` 被 `_lower_cond` 降级成两条守卫共享出口：

```
L:  jcc e  go, 1, L2
    jmp E
L2: jcc l  p, n, B
    jmp E
B:  ...body...   （`else { go = 0 }` 之后紧接着回边 `jmp L`）
```

`go` 只在"该退出了"的分支里被置 0，所以它其实是 **break 的一个笨写法**：
每轮迭代都要白付一次 `cmp go, 1` + 一个分支。b9_json 的
`jws`/`jstr`/`jnum` 三个扫描循环**每字节**都付一次。

## 改法

认出这个形态后，把 `mov go, 0` 换成 `jmp E`（直接跳出），再把守卫那两条
指令删掉 —— 循环条件只剩真正的那一个。

**前提（缺一不可，全部 fail-fast 拒绝）**：

1. `go` 在循环外**只定义一次**，值是让守卫为真的立即数；
2. 循环内对 `go` 的每次定义都是 `mov go, 0`；
3. **只能有一处** `go = 0`，且它到回边之间只允许有 label
   （`if ... { p+=1 } else { go=0 }` 的汇合 label 会落在中间）；
4. `go` 除了这条守卫**没有别的读**（循环外读它就会看到恒为 1 的错值）。

**回边不能删**：then 分支跳到汇合 label 之后仍然要回循环头。只改
`go = 0` 那一条。

**必须放在所有依赖循环结构的 pass 之后**：改完 `loop_regions` 就看不到
这个循环了（虽然回边还在，但头部形状变了），LICM / 展开 / 越界消除都会
失效。所以它排在 `opt_bounds_dedupe` 之后、`opt_schedule` 之前。

## 效果

b9_json 的 `jws` 循环 **23 → 20 条**（累计：v2.67 的 26 条 → 现在 20 条），
守卫从 `cmp/je/jmp/cmp/jl/jmp` 六条降到 `cmp/jl/jmp` 三条。

本机 min of 5，两轮交替 A/B：

| 基准 | 无 | 有 |
|---|---|---|
| b9_json | 33.1 / 33.9 | **29.6 / 29.0** |

**−11 ~ −14%**，两轮一致。

## 回归

`tests/run_win_tests.py`：**PASS=297 FAIL=0 SKIP=1**（含 t150）。

夹具 `t150_flag_loop` 专门覆盖**"不该改"的三种情况**（每条都跟手工算出的
期望值对拍，不是只跟另一条路径比）：

| 用例 | 为什么不改 / 改后语义 |
|---|---|
| `go = 0` 之后还有语句 | 改成 break 会跳过它们 |
| `go` 在循环外被读 | 改完 `go` 永远是初值 1 |
| 多个 `go = 0` | 汇合后无法保证回边只被它到达 |
| `while go != 0 && ...` | ne 版本，同样处理 |

验证过夹具抓得住：把"`go` 没有别的读"这个检查去掉，
立刻 `assert failed: 循环外读 go`。
